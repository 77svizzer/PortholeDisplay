# Porthole WebRTC

Простое и безопасное веб-приложение для удаленного доступа и демонстрации экрана через браузер без необходимости устанавливать клиентские программы для зрителей.

## Возможности

- Работа по прямой ссылке в браузере (WebRTC P2P)
- Трансляция экрана со звуком микрофона
- Многопользовательский просмотр с отображением списка участников и счетчика зрителей
- Разграничение прав: режим «только просмотр» по умолчанию, возможность выдавать и забирать права управления мышью и клавиатурой конкретным зрителям
- Возможность ведущего исключать участников (Kick)
- Прямой P2P-чат и передача файлов через WebRTC DataChannel
- Естественное управление мышью без блокировки курсора (Pointer Lock)
- Защита от атак: CSP, X-Frame-Options, защита от CSWSH через локальный токен, ограничение частоты запросов, валидация входных данных

## Архитектура

1. `server.py` — Python HTTP и WebSocket сервер сигнализации (порт 8000). Раздает статические файлы и согласует WebRTC-сессии.
2. `host_agent.py` — локальный агент ведущего (порт 8765, доступен только с localhost). Выполняет действия с мышью и клавиатурой по защищенному токену.
3. `public/` — веб-интерфейс (HTML, CSS, JS).

## Запуск

1. Установка зависимостей:
   ```bash
   pip install -r requirements.txt
   ```

2. Запуск локального сервера:
   ```bash
   python server.py
   ```

3. Запуск агента ввода (для ведущего):
   ```bash
   python host_agent.py
   ```

4. Запуск с публичным доступом через Pinggy:
   Запустите файл `start_public.bat`.
